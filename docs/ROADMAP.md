# QuickCalc 路线图

## v0.1 — 可运行 MVP

- [x] Tauri 2 + Rust + 原生 TypeScript 框架。
- [x] Windows 优先的窗口与后台生命周期。
- [x] 默认全局快捷键与开机自启动。
- [x] 数学、位运算、进制、变量和只读内置变量。
- [x] 双 Enter 复制与括号补全。
- [x] 50 条历史、变量与设置原子持久化。
- [x] 核心解析器和括号逻辑单元测试。
- [x] 中文/全角表达式输入自动归一化。
- [x] 应用图标与标签触发的 Windows x64 MSI/NSIS 自动 Release。
- [x] “源表达式.进制”转换语法与小数进制输出。
- [x] `/help` 命令模块、`/plugin` 管理入口与插件注册接口。
- [ ] 在 Windows 10/11 真机执行完整验收。

## v0.2 — Windows 首发质量

- 设置页：快捷键重绑定、自启动开关、失焦隐藏开关、主题与精度。
- 快捷键冲突的可视化诊断与恢复入口。
- 历史搜索、单条复制、清空历史和变量管理。
- 单实例保护；二次启动直接呼出已有窗口。
- Windows x64/ARM64 CI 构建、安装/卸载与升级测试。
- 冷启动、空闲 CPU、常驻内存与 10k 表达式基准。
- 崩溃恢复和损坏 JSON 故障注入测试。

## v0.3 — 命令与扩展能力

- 可信插件目录、清单校验与显式授权加载。
- `/plugin install|update` 与插件版本兼容检查。
- 插件设置持久化、权限声明和故障隔离。
- 更多内置命令、命令搜索与快捷命令面板。

## v0.4+ — 安装包签名与 Apple/Linux（已延后）

- 为 Windows 安装包接入受信任的代码签名并验证 SmartScreen。
- macOS Apple Silicon/Intel 签名、公证和登录项验证。
- Linux AppImage/deb/rpm 打包。
- X11 全局快捷键验证；Wayland 门户/桌面环境兼容矩阵。
- 平台原生快捷键文案与可选 `Command` 组合。

## 后续候选

- 任意精度整数与高精度十进制。
- 角度/弧度切换、单位换算、日期时间计算。
- 自定义函数与常用表达式收藏。
- 可选的便携模式与加密备份；仍保持默认纯本地、无遥测。
