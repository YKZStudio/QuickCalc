# QuickCalc 产品规格（v0.1）

## 1. 产品定位

QuickCalc 是面向高频键盘用户的常驻桌面计算器。用户无需切换到完整计算器应用，只需按全局快捷键、输入表达式并回车，即可得到结果或复制结果。

优先级顺序：

1. Windows 10/11（x64 首发，随后补 ARM64）。
2. Apple 平台（Apple Silicon 优先，同时验证 Intel；延后到 v0.4+）。
3. 主流 Linux 桌面（延后到 v0.4+，先验证 Ubuntu LTS 的 X11；Wayland 全局快捷键能力单独适配）。

## 2. 核心用户流程

1. 系统启动后，QuickCalc 静默在后台运行。
2. 用户按 `Ctrl + Shift + Space`，窗口在屏幕中央显示并聚焦输入框。
3. 用户输入表达式。输入左括号时自动插入右括号；求值前可补齐末尾缺失的右括号。
4. 第一次按 Enter：求值、更新 `res`、同步持久化并显示结果。
5. 表达式未变化时再次按 Enter：复制结果到系统剪贴板并显示轻量提示。
6. 再次按全局快捷键、按 Escape、关闭窗口或切换焦点：同步持久化并隐藏窗口，进程继续驻留。

## 3. 功能要求

### 3.1 窗口与生命周期

- 默认全局快捷键：`Ctrl + Shift + Space`。
- 快捷键为切换动作：隐藏时显示，显示时隐藏。
- 主窗口无系统边框、不可调整大小、始终置顶、默认不出现在任务栏。
- 失去焦点自动隐藏；关闭窗口等价于隐藏，不退出后台进程。
- 提供显式“退出”动作，以便真正结束后台进程。
- 开机自启动默认开启；自启动参数为 `--autostart`，此时不显示窗口。
- 快捷键被其他软件占用时，应用应继续启动，并在后续设置界面提示冲突。

### 3.2 表达式语言

支持：

- 数学运算：`+`、`-`、`*`、`/`、`%`、`**`。
- 根式与函数：`√x`、`sqrt(x)`、`cbrt(x)`、`root(value, degree)`、`pow(x, y)`。
- 常用函数：`abs`、`floor`、`ceil`、`round`、`trunc`、`sin`、`cos`、`tan`、`asin`、`acos`、`atan`、`ln`、`log`/`log10`、`exp`、`min`、`max`。
- 位运算（64 位有符号整数）：`&`、`|`、`^`/`xor`、`~`、`<<`、`>>`。
- 进制字面量：`0b1010`、`0o755`、`0xff` 和十进制。
- 进制输出：`expression.bin|oct|dec|hex`，例如 `0b1010.oct`、`12345.6789.hex`；支持整数和小数结果。
- ASCII 转换：`text.ascii` 输出以空格分隔的十进制 ASCII 编码；`code[ code...].tostr` 或逗号分隔形式把 0–127 的编码转回字符（串）。
- 分组符号：`()`, `[]`, `{}`；求值前统一成圆括号。
- 输入归一化：全角数字/字母/ASCII 标点，以及 `（）`、`【】`、`，`、`。`、`×`、`÷`、Unicode 减号等常见中文输入，求值前自动转换为英文半角表达式。
- 变量名：ASCII 字母或下划线开头，后接字母、数字或下划线；大小写不敏感。
- 赋值：`name = expression`。

运算符优先级从高到低：括号/函数、乘方、单目运算、乘除取模、加减、移位、按位与、按位异或、按位或。

### 3.3 变量

| 变量 | 含义 | 可否修改 |
| --- | --- | --- |
| `pi` | 圆周率 | 否 |
| `e` | 自然常数 | 否 |
| `res` | 上一次成功表达式的数值结果 | 否 |
| `tmstamp` | 当前 Unix 秒时间戳 | 否 |
| `tmlocal` | 电脑本地时间，显示为 `yyyy-mm-dd hh:mm:ss` | 否 |
| `tmutc` | 世界协调时（UTC），显示为 `yyyy-mm-dd hh:mm:ss` | 否 |
| 用户变量 | 用户通过 `name = expression` 创建 | 是 |

尝试为内置变量赋值必须返回清晰错误，且不得更改历史记录或持久化状态。

三个时间变量在同一次表达式求值中引用同一时刻。时间点可以保存到用户变量，两个时间点相减得到时间差；时间差显示为 `0000-00-dd hh:mm:ss`，年月固定为零，天数不受两位宽度限制。时间点可以加减普通秒数或时间差，但两个时间点不能相加。变量和 `res` 需要同时持久化其数值类型，以便重启后继续正确显示和计算时间差。

### 3.4 历史与持久化

- 最多保存 50 条成功计算，最新记录在前。
- 每条记录包含：唯一 ID、Unix 毫秒时间戳、原表达式、展示结果和可选数值结果；ASCII 字符转换等纯文本结果的数值为空。
- 用户变量与 `res` 跨重启保留。
- 设置与运行数据分别保存在系统应用数据目录中的 `settings.json`、`runtime.json`。
- 每次成功计算都采用“临时文件 → 同步磁盘 → 备份旧文件 → 替换”的流程，完成写入后才向界面返回成功。
- 窗口隐藏和正常退出时再次刷新当前状态。
- 对无法拦截的强制终止，保证此前已经返回成功的计算已尝试同步落盘；不能承诺保存尚未完成的输入或正在执行的计算。

### 3.5 命令与插件接口

- 以 `/` 开头的输入进入命令注册表，不发送到表达式求值器，也不写入计算历史。
- `/help [命令]` 显示表达式用法、命令列表或指定命令的帮助。
- `/plugin` 支持列出、启用、停用和移除已由可信宿主加载的插件。
- 插件通过 `QuickCalcPlugin` 激活接口注册命令；停用插件时必须注销其命令。
- v0.1 不从磁盘或网络发现、下载或执行第三方插件，安装器、权限模型与隔离机制留待后续版本。

### 3.6 本地化

- 支持简体中文（`zh-CN`）、繁体中文（`zh-TW`）和美式英语（`en-US`）。
- `zh-CN`、`zh-SG`、`zh-Hans` 系统语言映射到简体中文；`zh-TW`、`zh-HK`、`zh-MO`、`zh-Hant` 映射到繁体中文。
- 其他系统语言全部回退到美式英语，包括非美式英语地区。
- 主界面、无障碍标签、状态提示、内置命令及 Rust 后端用户可见错误必须使用同一语言策略。
- 启动时自动读取系统语言；v0.1 不提供手动语言选择，系统语言在应用运行期间变化后需重启 QuickCalc 生效。

## 4. 非功能要求

- 空闲时不轮询、不做网络请求，CPU 占用应接近 0%。
- 首发 Windows 冷启动目标：典型设备小于 500 ms（需在发布构建中实测）。
- 常驻内存目标：Windows 发布构建小于 50 MB（作为工程目标，不在框架阶段声称达成）。
- 单次普通表达式求值目标：小于 10 ms。
- 表达式最大长度暂定 4096 字符；解析深度后续增加显式上限，避免恶意或误输入耗尽栈。
- 全程离线；默认不收集遥测。
- JSON 损坏时尝试读取 `.bak`；仍失败则回退默认值并保留损坏文件供诊断。

## 5. 错误与边界

- 除零、函数定义域错误、非有限结果、未知变量、非法字符、括号不匹配均显示可读错误。
- 位运算拒绝小数、非有限值、超出 `i64` 范围的值，以及不在 0–63 的移位量。
- 非十进制输出允许小数，整数部分必须位于 64 位有符号范围内；负数显示为带负号的常规进制形式，而非二进制补码长串。
- `^` 和关键字 `xor` 固定表示按位异或；乘方只使用 `**` 或 `pow(x, y)`。
- 三角函数 v0.1 使用弧度。

## 6. v0.1 验收标准

- Windows 上安装后可设置自启动，并能通过默认快捷键可靠显示/隐藏。
- 失焦、Escape 和关闭动作均只隐藏窗口。
- 文档中的表达式示例通过核心单元测试。
- 连续计算超过 50 次后，重启只保留最新 50 条。
- 成功计算后强制结束进程并重启，历史、变量和 `res` 均能恢复。
- 同一表达式第一次 Enter 求值、第二次 Enter 复制。
- 用户无法覆盖 `pi`、`e`、`res`。
- 使用中文输入法键入 `（２＋３）×４` 可被自动转换并得到 `20`。
- `0b1010.oct` 得到 `0o12`，`12345.6789.hex` 得到 `0x3039.adcc63f142`。
- `tmlocal` 与 `tmutc` 使用 `yyyy-mm-dd hh:mm:ss` 显示；保存的两个时间点相减后按时间差格式显示。
- `Hello.ascii` 得到 `72 101 108 108 111`，`72 101 108 108 111.tostr` 得到 `Hello`。
- `/help` 显示用法，`/plugin` 在没有已加载插件时给出明确状态和管理帮助。
- 在简中、繁中和美式英语系统环境中，界面、命令和求值错误使用对应语言；`fr-FR` 等不支持的语言使用美式英语。
