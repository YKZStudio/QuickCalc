# QuickCalc

一个轻量（可能？）、顺手、好用的计算器

QuickCalc 是一款以键盘为中心的快速桌面计算器。默认按 `Ctrl + Shift + Space` 呼出，再按一次隐藏；窗口始终置顶、无边框，并在失去焦点时自动隐藏。

项目当前处于 **v0.1 框架阶段**：桌面生命周期、持久化、表达式求值核心、命令系统、插件接口、基础界面和 Windows 安装包自动发布流程已经搭好；代码签名与 Apple/Linux 支持已延后到后续发布阶段。

## 设计目标

- Windows 优先；Apple 平台与 Linux 的适配延后到 v0.4 及以后。
- 后台常驻时尽量少占用 CPU 和内存。
- 不依赖网络，表达式与历史记录只保存在本机。
- 每次成功计算先同步写盘，再把结果返回界面；历史记录最多保留 50 条。
- 交互足够快：一次回车计算，同一表达式再次回车复制结果。

## 已搭建的能力

- 全局快捷键显示/隐藏主窗口。
- 开机自启动；自启动时静默驻留后台。
- 无边框、置顶、跳过任务栏、失焦隐藏。
- 四则运算、取模、乘方、根式与常用数学函数。
- 64 位有符号整数位运算：`&`、`|`、`^`/`xor`、`~`、`<<`、`>>`。
- 二/八/十/十六进制字面量和输出转换。
- `/help` 命令帮助与 `/plugin` 插件管理入口。
- 可注册命令的 `QuickCalcPlugin` 插件接口。
- 用户变量赋值；内置只读变量 `pi`、`e`、`res`。
- 圆括号、方括号、花括号自动补全并统一参与求值。
- 自动把全角数字、中文括号和常见中文数学标点转换成解析器支持的英文形式。
- 设置、变量、`res` 和 50 条历史记录的崩溃友好型原子持久化。

## 表达式示例

| 目的 | 输入 | 结果示例 |
| --- | --- | --- |
| 四则运算 | `(2 + 3) * 4` | `20` |
| 乘方 | `2 ** 10` 或 `pow(2, 10)` | `1024` |
| 根式 | `sqrt(81)`、`root(32, 5)` 或 `√81` | `9`、`2` |
| 位运算 | `(0xff & 0b1010) << 2` | `40` |
| 异或 | `5 ^ 3` 或 `5 xor 3` | `6` |
| 进制转换 | `0b1010.oct`、`12345.6789.hex` | `0o12`、`0x3039.adcc63f142` |
| 定义变量 | `tax = 0.09` | `0.09` |
| 使用变量 | `199 * (1 + tax)` | `216.91` |
| 使用上次结果 | `res / 2` | 上次结果的一半 |

进制转换使用“源表达式.进制”后缀，目标支持 `bin`、`oct`、`dec`、`hex`，并支持小数。位运算只接受可表示为 64 位有符号整数的值。`^` 与 `xor` 均表示按位异或；乘方使用 `**` 或 `pow(x, y)`。

## 命令与插件

- `/help`：显示表达式、进制转换和命令用法；`/help plugin` 可查看指定命令。
- `/plugin` 或 `/plugin list`：列出已加载插件。
- `/plugin enable <id>`、`/plugin disable <id>`、`/plugin remove <id>`：管理已由可信宿主加载的插件。

`src/plugins.ts` 导出 `QuickCalcPlugin`、`PluginContext` 和 `PluginManager`，插件可在启用时注册新命令。当前版本只提供接口和运行期管理，不从磁盘或网络加载第三方代码。

## 开发

前置环境：Node.js 20+、Rust 1.77.2+，以及目标平台所需的 [Tauri 2 系统依赖](https://v2.tauri.app/start/prerequisites/)。

```bash
npm install
npm run tauri dev
```

常用检查：

```bash
npm test
npm run typecheck
npm run build
cd src-tauri && cargo test
```

## 技术选型

- **Tauri 2 + Rust**：复用系统 WebView，后台逻辑由原生进程承担，适合小体积、低常驻开销的桌面工具。
- **原生 TypeScript + CSS**：不引入前端框架和运行时状态库，降低启动与维护成本。
- **自研小型 Pratt 风格解析器**：明确控制运算符优先级、只读变量和位运算语义，不执行任意代码。
- **命令注册表 + 插件管理器**：内置命令与扩展命令使用同一受控接口，插件停用时自动注销命令。
- **JSON 原子写入**：文件可读、便于诊断；临时文件与备份文件用于处理中途终止。
