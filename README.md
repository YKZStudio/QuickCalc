# QuickCalc

一个轻量（可能？）、顺手、好用的计算器

QuickCalc 是一款以键盘为中心的快速桌面计算器。默认按 `Ctrl + Shift + Space` 呼出，再按一次隐藏；窗口始终置顶、无边框，并在失去焦点时自动隐藏。

当前版本为 **v0.2.2**：加入设置页（快捷键、自启动、失焦隐藏、精度、显示字体和 GitHub 更新检查）、历史搜索、单实例唤起与插件目录清单校验；Windows 安装包由 GitHub Actions 构建，再由维护者手动发布。

## 设计目标

- Windows 优先；Apple 平台与 Linux 的适配延后到 v0.4 及以后。
- 后台常驻时尽量少占用 CPU 和内存。
- 不依赖网络，表达式与历史记录只保存在本机。
- 每次提交的表达式（包括解析或求值失败）先同步写盘，再把结果或错误原因返回界面；历史记录最多保留 100 条。
- 交互足够快：一次回车计算并清空输入框，空输入再次回车复制上次结果。

## 已搭建的能力

- 全局快捷键显示/隐藏主窗口。
- 开机自启动；自启动时静默驻留后台。
- 无边框、置顶、跳过任务栏、失焦隐藏。
- macOS 风格双栏界面；红色窗口按钮用于隐藏，右上角“退出”按钮用于结束进程。
- 自动跟随系统颜色，也可用 `/color light`、`/color dark`、`/color auto` 手动切换。
- 内容超出当前高度时，窗口下边缘使用缓出动画向下扩展，并限制在显示器工作区内。
- 四则运算、取模、乘方、根式与常用数学函数。
- 64 位有符号整数位运算：`&`、`|`、`^`/`xor`、`~`、`<<`、`>>`。
- 二/八/十/十六进制字面量和输出转换。
- ASCII 字符串与十进制编码序列互转。
- UTF-8 文本 Base64 编码，以及 Base64/ASCII 自动识别解码。
- 变量、斜杠命令和点操作的输入补全；上/下键浏览表达式历史并保留当前未提交草稿。
- 补全项左侧显示名称、右侧显示简短说明，例如 `pi — 圆周率`、`/color — 查看或修改界面颜色模式`。
- `/help` 命令帮助、`/clean` 历史清理、`/del <变量名>` 用户变量删除、`/color` 主题切换与 `/plugin` 插件管理入口。
- 可注册命令的 `QuickCalcPlugin` 插件接口。
- 用户变量赋值与列表垃圾桶快捷删除；内置只读变量 `pi`、`e`、`res`、`tmstamp`、`tmlocal`、`tmutc` 不可删除。
- 圆括号、方括号、花括号自动补全并统一参与求值。
- 自动把全角数字、中文括号和常见中文数学标点转换成解析器支持的英文形式。
- 界面、命令帮助和后端错误支持简体中文、繁体中文与美式英语，并跟随系统语言。
- 设置、变量、`res` 和 100 条历史记录的崩溃友好型原子持久化。

## 表达式示例

| 目的 | 输入 | 结果示例 |
| --- | --- | --- |
| 四则运算 | `(2 + 3) * 4` | `20` |
| 乘方 | `2 ** 10` 或 `pow(2, 10)` | `1024` |
| 根式 | `sqrt(81)`、`root(32, 5)` 或 `√81` | `9`、`2` |
| 位运算 | `(0xff & 0b1010) << 2` | `40` |
| 异或 | `5 ^ 3` 或 `5 xor 3` | `6` |
| 进制转换 | `0b1010.oct`、`12345.6789.hex` | `0o12`、`0x3039.adcc63f142` |
| 定义变量 | `tax = 0.09` | `0.09` |
| 使用变量 | `199 * (1 + tax)` | `216.91` |
| 使用上次结果 | `res / 2` | 上次结果的一半 |
| 查看 Unix 时间戳 | `tmstamp` | 当前 Unix 秒时间戳 |
| 查看本地时间/UTC | `tmlocal`、`tmutc` | `yyyy-mm-dd hh:mm:ss` |
| 计算时间差 | `start = tmstamp`，稍后输入 `tmstamp - start` | `0000-00-00 00:01:30` |
| 字符串转 ASCII | `Hello.ascii` | `72 101 108 108 111` |
| ASCII 转字符串 | `72 101 108 108 111.tostr` | `Hello` |
| 字符串转 Base64 | `Hello.base64`、`你好.base64` | `SGVsbG8=`、`5L2g5aW9` |
| Base64 转字符串 | `SGVsbG8=.tostr` | `Hello` |

输入 `数据.` 或点操作的前几个字母后会显示补全列表，可用方向键选择、Tab 接受。可补全操作包括 `bin`、`oct`、`dec`、`dex`、`hex`、`ascii`、`base64` 和 `tostr`；`dex` 是十进制输出 `dec` 的兼容别名。

进制转换使用“源表达式.进制”后缀，目标支持 `bin`、`oct`、`dec`/`dex`、`hex`，并支持小数。位运算只接受可表示为 64 位有符号整数的值。`^` 与 `xor` 均表示按位异或；乘方使用 `**` 或 `pow(x, y)`。

`tmstamp`、`tmlocal` 与 `tmutc` 在每次求值时读取同一个当前时刻。把任一时间变量保存到用户变量后，可以与另一个时间点相减；时间差使用 `0000-00-dd hh:mm:ss`，其中年月固定为 `0000-00`，天数可继续增长，从而避免把长度不固定的月份或年份当作固定时长。

ASCII 转换严格使用 0–127：`.ascii` 输出空格分隔的十进制编码。`.base64` 把点号前的文本按 UTF-8 编码为标准 Base64；如文本包含 `=`，可使用引号明确数据边界，例如 `"a=b".base64`。`.tostr` 会自动识别输入：只包含数字、空格或逗号时按 ASCII 编码序列处理，否则按 Base64 解码，并兼容省略末尾填充的 Base64。Base64 解码结果必须是有效 UTF-8。文本转换结果不覆盖数值变量或 `res`。

## 语言

QuickCalc 启动时读取系统语言并自动选择：

- `zh-CN`、`zh-SG`、`zh-Hans`：简体中文。
- `zh-TW`、`zh-HK`、`zh-MO`、`zh-Hant`：繁体中文。
- 其他任何语言（包括其他英语地区）：统一使用美式英语 `en-US`。

语言选择同时作用于主界面、无障碍标签、状态提示、`/help`、`/clean`、`/del`、`/color`、`/plugin` 和 Rust 后端返回的错误信息；当前不提供手动语言覆盖设置。

## 命令与插件

- `/help`：显示表达式、点操作、Base64/ASCII 转换和命令用法；`/help plugin` 可查看指定命令。
- `/clean`：清空本机保存的全部计算历史，不删除变量与 `res`。
- `/del <变量名>`：删除一个用户变量；内置变量和常量不可删除。变量列表最右侧的红色垃圾桶按钮执行相同操作。
- `/color`：查看当前颜色模式；`/color light`、`/color dark`、`/color auto` 分别切换亮色、暗色或跟随系统。
- `/plugin` 或 `/plugin list`：列出已加载插件。
- `/plugin enable <id>`、`/plugin disable <id>`、`/plugin remove <id>`：管理已由可信宿主加载的插件。

`src/plugins.ts` 导出 `QuickCalcPlugin`、`PluginContext` 和 `PluginManager`，插件可在启用时注册新命令。当前版本只提供接口和运行期管理，不从磁盘或网络加载第三方代码。

## 开发

前置环境：Node.js 20+、Rust 1.77.2+，以及目标平台所需的 [Tauri 2 系统依赖](https://v2.tauri.app/start/prerequisites/)。

```bash
npm install
npm run tauri dev
```

常用检查：

```bash
npm test
npm run typecheck
npm run build
cd src-tauri && cargo test
```

## Windows 发布

推送到 `main` 或手动触发工作流后，GitHub Actions 会构建未签名的 Windows x64/ARM64 NSIS `.exe` 与 MSI，并作为 Actions artifacts 上传。维护者下载并验证产物后，再手动发布到 GitHub Releases；具体步骤见 [发布说明](docs/RELEASE.md)。

## 技术选型

- **Tauri 2 + Rust**：复用系统 WebView，后台逻辑由原生进程承担，适合小体积、低常驻开销的桌面工具。
- **原生 TypeScript + CSS**：不引入前端框架和运行时状态库，降低启动与维护成本。
- **自研小型 Pratt 风格解析器**：明确控制运算符优先级、只读变量和位运算语义，不执行任意代码。
- **命令注册表 + 插件管理器**：内置命令与扩展命令使用同一受控接口，插件停用时自动注销命令。
- **JSON 原子写入**：文件可读、便于诊断；临时文件与备份文件用于处理中途终止。
